# Tide 精简导航归并方案

| 新栏目 | 主链接 | 归并内容 |
|---|---|---|
| TIDE | `/` | 品牌主页、核心定位与广州工厂摘要 |
| SCIENCE | `/about` | 肽类研发、生产流程、质量体系与技术能力 |
| PEPTIDES | `/products` | 产品目录、规格型号与产品资料 |
| QUALITY | `/coa` | COA 报告、公开批次资料与质量文件 |
| FACILITY | `/services` | 工厂能力、OEM/ODM、包装交付与合作流程 |
| ABOUT | `/feedback` | 客户反馈、收货记录与品牌合作证明 |
| CONTACT | `/contact` | 联系方式、WhatsApp 和询盘入口 |

订单与发货页面 `/order` 保留为可访问的内容页面，并从主页和相关页面内部链接进入，不再占用顶部主导航位置。
