# 参考网站观察

## 同行 1：zjys-tech.com
页面强调“Professional Biotech Peptide Lyophilized Powder Manufacturer”，突出研发、生产、OEM/ODM 与全球出口。当前页面在浏览器中主要呈现大字号深蓝标题、浅灰背景与蓝色 CTA，视觉较基础，适合作为信息结构参考而非视觉范本。

## 同行 2：jianxilab.com
导航包含 Home、Product、About Us、Feedback、Contact Us 与 WhatsApp；首页采用实验室设备大图轮播，叠加居中白色主标题。其后依次是产品分类卡、About Us、客户统计、客户反馈、Feedback 内容与页脚联系方式。视觉使用暖桃色/浅米色分区、深蓝标题、圆角产品卡与大量中心对齐标题。

## 本站设计决策
保留同行常见的“可信度—质量文件—客户反馈—联系转化”信息路径，但避免复制大段居中和普通电商卡片。采用更高端的“实验室编辑部”方向：暖象牙底色、深墨蓝文字、可识别的青绿色品牌色、非对称布局、细线标记与纸张/档案感 COA 展示。客户反馈仅使用可替换的示例占位结构，不伪造真实用户评价或姓名；正式内容应由用户提供后再填充。
