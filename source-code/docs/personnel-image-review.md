# Tide 人物素材复核记录

## 复核标准

人物画面仅在能够支持“中国广州肽工厂”语境时保留。根首页优先使用中国/亚洲工厂人员，或完全不出现人物的洁净室、仪器、托盘与批次画面。COA、产品、反馈、服务和联系页面没有新增人物宣传图，不把无法确认身份的欧美访客当作 Tide 员工或客户证明。

## 结论

根首页不再展示欧美访客。保留的人物画面均来自广州工厂/实验室语境，且用 alt 文本明确为 Asian Tide factory staff 或 Asian laboratory personnel；其余视觉位使用设备、洁净空间、批次托盘或档案文件。管理员媒体库中的历史素材仍可继续管理，但不代表它们会自动回到根首页，除非被重新分配到对应首页槽位。
