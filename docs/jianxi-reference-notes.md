# JianxiLab 参考交互拆解

参考地址：[JianxiLab](https://www.jianxilab.com/)

## 可借鉴的结构

JianxiLab 首页的核心是一个大幅背景图 Hero，中央叠加大字号白色品牌文案；左右两侧有独立的轮播切换按钮，文字与背景图在切换时同步变化。首屏下方直接连接产品分类卡片，使用户从品牌承诺进入产品浏览。

## Tide 的原创转化方案

Tide 不直接复制 JianxiLab 的文案、布局细节或图片，而采用自己的 Tide Blue 编辑式系统：首屏使用广州工厂/洁净生产/批次文件等不同素材；左下角保留章节编号与工厂定位，中央或偏左叠加可读的英文主张；右侧使用细线箭头按钮；底部加入当前幻灯片进度与“Explore facility / View products / Review COA”等 Tide 专属 CTA。轮播中的人物只使用亚洲/中国工厂人员，其他画面使用设备、洁净区或批次实拍，确保同一轮播组不重复图片。

## 参考页面观察到的风险

参考站的自动文字截断为“most relia”，且客户评价区域包含明显虚构姓名/内容。Tide 不复制这些做法：首页只使用完整可读文案，并继续使用真实 COA、真实批次照片和真实反馈档案；不新增虚构评价或虚构客户数据。
